# 📖 Daily English — AI Coding Tools in the Workplace
**Date:** 2026-07-20 | **Level:** A2-B1

## 📖 Reading — Bài đọc hôm nay nói về cách các developer đang làm việc cùng với công cụ lập trình AI (AI coding tools) trong môi trường công sở hiện đại.

**7 Điều Developer Nên Biết Khi Làm Việc Với AI Coding Tools**
*(7 Things Developers Should Know About Working With AI Coding Tools)*

1. AI không thay thế bạn (AI doesn't replace you) — nó là một công cụ hỗ trợ (it's a support tool). Bạn vẫn là người (You're still the one) đưa ra quyết định cuối cùng (making the final decision).

2. Đừng mù quáng tin vào code (Don't blindly trust the code) mà AI tạo ra (that AI generates). Luôn luôn kiểm tra lại (Always double-check) trước khi merge vào production (before merging into production).

3. Viết prompt rõ ràng (Write clear prompts) là một kỹ năng quan trọng (is an important skill). Prompt càng chi tiết (The more detailed the prompt), kết quả càng tốt (the better the result).

4. AI tools hoạt động tốt nhất (AI tools work best) với những task lặp đi lặp lại (with repetitive tasks) như viết unit test (like writing unit tests), refactor code (refactoring code), hoặc tạo boilerplate (or generating boilerplate).

5. Đừng quên code review (Don't forget code review) — ngay cả khi AI viết code (even when AI writes the code). Bạn cần đọc hiểu từng dòng (You need to understand every line) trước khi approve (before approving).

6. Học cách debug code AI (Learn to debug AI-generated code) là điều bắt buộc (is a must). Đôi khi AI sẽ tạo ra (Sometimes AI will produce) những bug rất khó phát hiện (very hard-to-find bugs) vì code nhìn có vẻ đúng (because the code looks correct).

7. Kết hợp AI (Combining AI) với kiến thức domain của bạn (with your domain knowledge) mới là chìa khóa (is the real key). AI không biết (AI doesn't know) business logic của dự án bạn (your project's business logic) — chỉ có bạn mới biết (only you know that).

8. AI coding tools đang phát triển rất nhanh (are evolving very fast). Hãy dành thời gian (Take time) để cập nhật kiến thức thường xuyên (to update your knowledge regularly) — điều này giúp bạn (this helps you) không bị tụt lại phía sau (not fall behind).

## 💡 Quick Tip

Khi viết prompt cho AI coding tool, hãy dùng **cấu trúc 3 phần**: (1) **Context** — mô tả ngắn gọn dự án/file bạn đang làm, (2) **Task** — nói rõ bạn muốn AI làm gì, (3) **Constraints** — liệt kê những giới hạn hoặc yêu cầu cụ thể (ví dụ: "dùng ES6 syntax", "không dùng thư viện ngoài", "giữ nguyên coding style hiện tại"). Cấu trúc này giúp AI hiểu đúng ý bạn hơn và giảm số lần phải sửa lại code.

Ví dụ: *"Context: We're building a React dashboard. Task: Add a loading spinner that shows while data is fetching. Constraints: Use existing CSS variables, don't add new dependencies, keep it under 30 lines."*
